현재 연구의 비교 기준과 해석 — 2026-10-28 관측분

평가 기준
각 환경에서 800K, 900K, 1M의 성공률을 같은 비중으로 평균한다.
각 시점은 CPU 50개 에피소드, 초기화 seed42..91이다. 9개 환경과
학습 seed 또는 ensemble group도 같은 비중으로 평균한다. 최고 시점,
환경별 우승 방법의 혼합, 누락 결과의 0 대입은 사용하지 않는다.
목표는 제공된 plain FQL .47와 ReBRAC .44 초과이다. DD-ReBRAC .63과는
구분하며, .47 초과만으로 SOTA 또는 같은 계산량에서의 우위를 주장하지 않는다.

공식 스타일 정렬과 정책의 역할
공식 코드의 4층 GELU, navigation512/manipulation256, Q/V LayerNorm,
actor 비정규화, 공개 환경군 설정을 사용한다. 이는 방정식/구조/설정의
정렬이며 설치된 구버전 JAX 등의 차이까지 제거한 논문 수치 재현은 아니다.
IFQL의 행동 정책은 Q/V와 무관한 flow matching으로 데이터의 다봉 행동을
학습하고, 추론에서 9개 후보를 Q로 선택한다. 따라서 Gaussian의 모드
평균화 문제를 줄일 여지는 있지만, 잘못된 critic의 행동 순위를 고치지는 못한다.

기존 V2 보정은 설명 가능한 하나의 업데이트 묶음이다
고정된 old target-Q의 twin minimum으로 동일 minibatch의 V를 Adam 두 번
갱신하고, 갱신된 V의 next-state bootstrap을 알려진 비용 반환 범위로
투영한 뒤 Q와 actor를 한 번 갱신한다. 각 환경별로 임의의 가중치나
보정량을 튜닝하지 않는다. 다만 V 횟수, bootstrap 순서, 투영이 함께
바뀌므로 전체 차이를 각각의 단독 효과로 부르지는 않는다.

후보 수를 맞춘 새 전체 비교
seed0, gamma .999, tau .9, 공통 N9의 마지막3 평균:
  native IFQL .31259259, V2 IFQL .40888889.
54개 실제 checkpoint의 원본/소스/설정/finite/Adam 횟수를 확인했다.
두 방법의 실제 BC 가중치는 같지 않다. 종료 RNG 상태가 같다는 사실만으로
동일한 정책 후보를 사용했다고 볼 수 없고, 전체 상승분을 V 보정의 효과로
단정할 수 없다. 차이의 역사적 원인은 아직 확정하지 않았다.
이를 분리하려고 V2의 실제 BC를 공통으로 고정해 native Q와 V2 Q를
비교하는 27개 CPU50 교차 평가를 별도 등록했다. 먼저 세 환경에서
동일 모델 재조립의 전체 상태와 에피소드 배열이 정확히 일치해야 한다.
이 결과도 특정 BC에 조건부인 value-bundle 효과이며 독립 학습 재현은 아니다.

현재 후보들은 서로 다른 가설을 검증한다
1. 두 V fitting의 두 번째 minibatch만 새로 뽑는다. 같은 minibatch의
   fitting 개선이 새 행동/상태에 일반화되는지를 확인한다. Q/BC replay와
   V 전용 replay를 분리하고 실제 BC/optimizer/RNG 동일성을 검사한다.
2. 데이터 행동 분포를 학습한 flow의 9개 후보 Q에 대해 expectile을 직접
   푼다. 학습된 V가 bootstrap에 들어가지 않아 V 근사 residual을 제거한다.
   twin mean 버전은 twin minimum의 보수성이 누적되는 효과를 비교한다.
   finite 후보 오차, 행동 모델 오차, Q 오차, 신경망 Bellman fitting은 남는다.
   연구용으로 유지된 두 V 업데이트는 계산량 통제용이며 이 backup에 쓰이지 않는다.
3. 알려진 보상 성분 수 C로 p=1+(1-gamma)Q/C를 정의하고 Q/V를 sigmoid
   logit으로 표현한다. 모든 환경에서 같은 변환이며 C는 보상 정의에서
   정해지고 관측 성능이나 데이터의 임의 min/max로 튜닝하지 않는다.
   probability MSE와 asymmetric Bernoulli KL 두 점수 규칙을 비교한다.
   KL의 V-logit 미분은 w_tau*(pV-pQ)이므로 원래 expectile의 population
   root를 유지하면서 경계에서 sigmoid 미분이 추가로 작아지는 문제를 줄인다.
   Q에는 같은 원리의 soft-target BCE를 쓴다. shaped reward가 유지되므로
   p를 일반적인 이진 성공 확률이라고 부르지 않는다.
   raw 대비 unit 변환은 초기화와 출력 parameterization도 바꾸며,
   MSE 대비 KL은 Q와 V의 점수 규칙을 함께 바꾼다. 성능이 좋아지면 Q만/
   V만 바꾸는 요인 분해가 필요하다. 지금은 정책 성능 향상을 확정하지 않았다.

세 방법을 모두 쌓은 알고리즘이 아니다. 각 가설을 공통 규칙으로 비교하고
전체9와 새로운 학습 seed에서 살아남는 단일 방법을 선택해야 한다.

안정성과 성능은 구분한다
tau .99/gamma .999의 native Pz3 seed3은 양수 비용 가치가 수천까지 커지고
800K/900K/1M 성공률이 모두0이었다. 보정된 tau .99가 finite라도 성공률이
높다는 뜻은 아니다. 전체 학습/평가가 끝난 뒤 같은 기준으로 비교한다.
독립3 critic 평균 순위의 discovery .5459는 첫 fresh group .3481로
재현되지 않았다. 이 결과를 숨기거나 환경별 다른 방법으로 대체하지 않는다.

진단의 범위
성공으로 종료된 relabelled absorbing boundary에서는 Q/V의 참값0을
안다. 그 외 일반 상태의 참 Q나 조건부 expectile residual은 알지 못한다.
표본 fitting loss, score RMS, 상태 평균은 조건부 residual 또는 B_k의
직접 측정치가 아니다. frozen teacher fitting이 줄어도 교사의 오류는 남고,
평균 fitting과 성공 boundary 정확도가 반대로 움직일 수 있다.
서로 다른 teacher의 fitting loss는 참 Q 정확도의 대소 관계를 증명하지 않는다.
grad/norm은 tensor별 L2 norm의 합이며 global L2 norm이나 clipping이 아니다.
기존 일부 계획의 grad_norm 필드 누락은 0이라는 의미가 아니다.

새 unit 모델의 raw logit을 비용 가치로 해석했던 보조 진단 두 건은 잘못된
단위였다. SHA를 보존해 격리했고 전용 sigmoid 역변환 진단으로 대체했다.
학습, 원본 checkpoint/config, primary 성능 평가는 영향을 받지 않았다.
일반 dispatcher는 모든 custom return representation을 건너뛴다.

다음 결론의 조건
부분 환경/초기 checkpoint가 좋아도 목표 달성으로 취급하지 않는다.
새 방법은 전체9 동일 규칙의 마지막3 평균과 미사용 학습 seed>=9에서
독립 확인한 뒤 주장한다. 모든 실패와 계산량을 함께 남긴다.
